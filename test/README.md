# Pruebas del proyecto

Coloca aquí las nuevas pruebas `*.test.ts` de Vitest. Ya se cubren utilidades de migración, contraseñas, validación de fecha/franja por visita y estados de envío de acceso y alta de usuarios en `submit-feedback.test.ts`. Prioriza permisos por perfil, transiciones de estado, visitas con varias máquinas, documentos firmados y sincronización de las guías. Ejecuta `npm test`. No hay todavía una cobertura mínima establecida.
